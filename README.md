This project provides a comprehensive analysis of coffee shop sales, including key performance insights, product trends and a revenue forecast based on historical transaction data.

All analyses are contained in the Excel file Coffee_Sales_Analysis_and_Forecast.xlsx.

Data Source:

The dataset is based on publicly available data from the Kaggle platform, adapted and organized for analytical purposes.

File Structure - Excel Workbook Sheets:

Dashboard – Main overview of KPIs and trends

Forecast Sheet – Revenue prediction

Price Analysis – Price impact on product performance

Conclusions – Summary and recommendations

Data Validation - Data used for pivot tables and charts


Key Analyses:

Identification of top-selling coffee types

Revenue and demand trends over time


Hour-by-hour performance breakdown

Customer behavior by payment method

Price and revenue correlation

Forecasting based on historical sales

Tools & Methods:

Microsoft Excel

Pivot tables & dynamic charts

Trendline forecasting

Data cleaning and validation

Summary:

The workbook serves as a compact analytical package for understanding and forecasting coffee shop performance. It supports business decisions related to pricing, staffing, product strategy, and revenue planning.
